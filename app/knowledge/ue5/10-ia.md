# 10 Inteligência artificial (UE5)

## IA: peças principais
AAIController (controlador da IA; possui o Pawn), Behavior Tree (árvore de decisões), Blackboard (memória da IA), AI Perception (visão, audição, dano), EQS (escolha de locais), Navigation System com NavMesh (caminhos), State Tree (máquina de estados hierárquica, alternativa moderna à Behavior Tree), Smart Objects (objetos de interação reservados por agentes), Mass (simulação de multidões com ECS). Módulos C++: AIModule, NavigationSystem, GameplayTasks.

## IA: configurar o Pawn para ser controlado
No Pawn/Character: AIControllerClass = AMyAIController::StaticClass() e AutoPossessAI = EAutoPossessAI::PlacedInWorldOrSpawned. Para Characters, o Character Movement precisa de velocidade e o NavAgent configurado. Mover: AIController->MoveToActor(Alvo, RaioAceitavel) ou MoveToLocation, com o resultado em OnMoveCompleted (ReceiveMoveCompleted). Em Blueprint: AI Move To.

## Navegação: NavMesh
Coloque um Nav Mesh Bounds Volume cobrindo a área; aperte P na viewport para ver a área navegável em verde. Project Settings > Navigation Mesh: Runtime Generation (Static, Dynamic Modifiers Only, Dynamic) para obstáculos que se movem; tamanho do agente (raio, altura, degrau, inclinação). Nav Modifier Volume e Nav Area (custo, áreas proibidas). Nav Link Proxy liga pontos não conectados (pular de um telhado, descer uma escada). Com World Partition, use World Partitioned Navigation Mesh ou geração dinâmica. Se a IA não anda: confira NavMesh (P), possessão, velocidade e se o destino está na área navegável.

## Behavior Tree e Blackboard
Blackboard: chaves (Object TargetActor, Vector LastKnownLocation, Bool CanSeeTarget, Enum State). Behavior Tree: Composites (Selector tenta filhos até um ter sucesso; Sequence executa até um falhar; Simple Parallel), Tasks (Move To, Wait, Run EQS Query, tasks próprias), Decorators (condições como Blackboard Based Condition, Cooldown, Loop; com Observer Aborts Self/Lower Priority/Both para interromper quando a condição muda), Services (rodam periodicamente enquanto o ramo está ativo; ex.: atualizar distância). No AIController: RunBehaviorTree(BT) no OnPossess. Depure abrindo a árvore com o jogo rodando.

## Behavior Tree: task em C++
```cpp
UCLASS()
class MYGAME_API UBTTask_FindPatrolPoint : public UBTTaskNode
{
    GENERATED_BODY()
public:
    UBTTask_FindPatrolPoint() { NodeName = TEXT("Find Patrol Point"); }
    UPROPERTY(EditAnywhere, Category = "Blackboard") FBlackboardKeySelector PatrolLocationKey;
    UPROPERTY(EditAnywhere, Category = "Patrol") float Radius = 1000.f;
protected:
    virtual EBTNodeResult::Type ExecuteTask(UBehaviorTreeComponent& OwnerComp, uint8* NodeMemory) override
    {
        APawn* Pawn = OwnerComp.GetAIOwner() ? OwnerComp.GetAIOwner()->GetPawn() : nullptr;
        UNavigationSystemV1* Nav = UNavigationSystemV1::GetCurrent<UNavigationSystemV1>(GetWorld());
        FNavLocation Loc;
        if (Pawn && Nav && Nav->GetRandomReachablePointInRadius(Pawn->GetActorLocation(), Radius, Loc))
        {
            OwnerComp.GetBlackboardComponent()->SetValueAsVector(PatrolLocationKey.SelectedKeyName, Loc.Location);
            return EBTNodeResult::Succeeded;
        }
        return EBTNodeResult::Failed;
    }
};
```
Tasks longas retornam InProgress e chamam FinishLatentTask depois. Em Blueprint, derive de BTTask_BlueprintBase (Receive Execute AI e Finish Execute).

## AI Perception
No AIController, adicione UAIPerceptionComponent com configs: UAISenseConfig_Sight (SightRadius, LoseSightRadius, PeripheralVisionAngleDegrees, DetectionByAffiliation: marque Detect Neutrals para detectar sem times), UAISenseConfig_Hearing (HearingRange), UAISenseConfig_Damage. Ligue OnTargetPerceptionUpdated (AActor*, FAIStimulus; Stimulus.WasSuccessfullySensed() indica visto ou perdido). O jogador precisa de um UAIPerceptionStimuliSourceComponent registrado para Sight (ou auto registro). Sons: UAISense_Hearing::ReportNoiseEvent(World, Local, Volume, Instigator). Times: implemente IGenericTeamAgentInterface (GetGenericTeamId) no controller para afiliação Amigo/Inimigo/Neutro.

## EQS (Environment Query System)
Escolhe lugares: Generators (Points: Grid, Circle, Pathing Grid; Actors Of Class), Tests (Distance, Trace para linha de visão, Pathfinding, Dot, Overlap) que filtram e pontuam, e Contexts (Querier, alvo; contextos próprios em Blueprint ou C++). Usos: achar cobertura sem linha de visão do jogador, posição de flanco, ponto de fuga. Na Behavior Tree, a task Run EQS Query grava o resultado no Blackboard. Teste no editor com o ator EQS Testing Pawn.

## State Tree
Máquina de estados hierárquica com seletores, condições de entrada, tasks e transições, usada para IA e lógica de objetos (plugin StateTree; o GameplayStateTree para atores). Mais simples de raciocinar do que árvores grandes para comportamentos baseados em estados; integra com Smart Objects e Mass. Componente: UStateTreeComponent (ou UStateTreeAIComponent para IA). Tasks podem ser escritas em C++ (FStateTreeTaskBase) ou Blueprint.

## Smart Objects
Objetos com slots de uso (banco para sentar, balcão, cobertura) que agentes encontram, reservam (para dois NPCs não usarem o mesmo lugar) e usam com comportamentos definidos. Peças: Smart Object Definition, Smart Object Component no ator, Smart Object Subsystem para consultas e reservas, e Gameplay Behaviors ou tarefas de State Tree para executar o uso.

## Mass (multidões)
Framework ECS orientado a dados para milhares de entidades (multidões, tráfego), com processadores que operam em lote, representação por LOD (de atores completos a instâncias simples) e integração com State Tree e Smart Objects. O City Sample da Epic demonstra. Use quando atores comuns não escalam (centenas a milhares de agentes simultâneos).

## IA: depuração
Gameplay Debugger (tecla apóstrofo por padrão; configurável em Project Settings > Gameplay Debugger), com categorias no teclado numérico: navegação, Behavior Tree, EQS, percepção. Visual Logger (Tools > Debug > Visual Logger) grava o que a IA fez com linha do tempo; em C++ use UE_VLOG e UE_VLOG_LOCATION. Comando show Navigation e a tecla P mostram a NavMesh.

## IA: desempenho
Não rode Behavior Trees complexas para centenas de agentes distantes: use LOD de IA (reduzir a frequência de serviços e percepção com a distância, ou desligar a árvore), evite EQS frequentes e pesados, limite traces por frame, use Significance Manager para priorizar agentes perto do jogador e considere Mass para multidões.

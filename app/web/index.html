Backup das conversas

    

      

        
💾 Criar backup

        
Gera um arquivo .zip com todas as conversas (inclusive as do Codex e as imagens geradas). Guarde na nuvem, num pendrive ou em outro PC.

        

        
        

      

      

        
📂 Restaurar backup

        
Junta as conversas do backup com as que já existem aqui. Se a mesma conversa estiver nos dois, fica a versão mais recente. Nada é apagado.

        
        
        

        

      

      
Os modelos não entram no backup (são arquivos grandes que podem ser baixados de novo). Tokens e chaves de API também ficam de fora.
